# 🌌 Q&A Chatbot using LangChain + Ollama + Gemma 2B

A simple AI-powered Q&A chatbot built using **LangChain**, **Streamlit**, and the open-source **Gemma 2B** model running locally with **Ollama**.

---

# 🚀 Features

* Interactive Q&A Chatbot
* Local LLM using Ollama
* Open-source Gemma 2B model
* Streamlit frontend
* LangChain integration
* Adjustable model parameters

---

# 🛠️ Tech Stack

* Python
* LangChain
* Ollama
* Streamlit
* Gemma 2B

---

# 📦 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/alokitm/<repo-name>.git
```

---

## 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

---

## 3️⃣ Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

---

## 4️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

# 🤖 Install Ollama & Gemma Model

Install Ollama from:

https://ollama.com

Then pull the Gemma model:

```bash
ollama pull gemma:2b
```

---

# ▶️ Run the Application

```bash
python -m streamlit run app.py
```

---

# 🌐 Run on Localhost

After running the command, open:

```text
http://localhost:8501
```
